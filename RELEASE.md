# Before a public release

Snapshots (`cmsr release "<label>"`) can go out at any time. dEgi has not been reached, so
releases go out under the good-faith commitments in [NOTICE.md](NOTICE.md). A public release
waits for:

- [ ] bē (`BW.init`, `BW.medi`) hand-edited in every cut. The drawings in `drawings/<cut>.ufo`
      are accepted stand-ins: w moved up 60 under b, its root following the slope of u (dEgi's
      i after b). Huree's `BW.init` is still the build's automatic cut.
- [ ] The glyphs no 1998 key draws (status `new`): k2, zr, zhi, s final FVS1, birga, the
      Mongolian ellipsis and four dots.
